# BDIX Server Checker

A simple backend API built with Node.js and Express.js to check whether a URL is accessible from the current network.

## Features

- Check HTTP/HTTPS URL accessibility
- Return HTTP status code
- Return success/failure result
- Simple Express.js API
- Timeout handling
- Beginner-friendly project structure

## Technologies

- Node.js
- Express.js
- JavaScript
